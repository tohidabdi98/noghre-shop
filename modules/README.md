# modules/ — the module contracts of this project

One file per module: `<MODULE-ID>.md` (e.g. `AUTH-001.md`). Each file starts with a machine-readable
YAML block and continues with the required prose sections.

- **Format and rules:** `docs/modules/README.md`
- **Template:** `docs/modules/template.md`
- **Create one:** `python scripts/tp.py new-module --id AUTH-001 --name "Authentication" --dep USER-001`
- **Validate:** `python scripts/tp.py validate`
- **Live status** (not ownership) lives in `state/modules.yaml`; edges live in `state/dependencies.yaml`.

## Rules

1. **One owner per path.** `owns` sets must not overlap between modules
   (`docs/modules/README.md` §3). `tp.py validate` fails on overlap.
2. **Status is duplicated on purpose**: the contract's `status` field must equal the registry entry,
   and `tp.py start|handoff` keeps them in step. `tp.py validate` fails on drift.
3. **Contracts are amended by change request**, not silently edited during implementation.
4. **Every contract must pass** `python scripts/tp.py validate` before its module can become `ready`.
5. Delete a contract only when its module is `cancelled` — and record why in
   `docs/project/decisions.md`.
